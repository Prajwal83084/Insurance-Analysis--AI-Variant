Insurance Analytics Project

 Overview

This project focuses on building an end-to-end Insurance Analytics Dashboard to help organizations monitor performance, track KPIs, and improve strategic decision-making.

The project transforms raw insurance data into interactive dashboards that provide a centralized view of revenue, sales pipeline, renewals, and branch performance.

Objectives

Analyze insurance business performance
Track revenue, renewals, and sales pipeline
Evaluate branch and executive performance
Identify growth opportunities and revenue risks
Build interactive dashboards for business insights

 Dataset Description

The dataset includes:

Policy Data – Premiums, renewals, policy types
Opportunity Data – Pipeline, deal stages
Revenue Data – Brokerage, invoices
Account Executive Data – Sales performance
Branch Data – Location-wise performance
Meeting Data – Sales activities

 Data Processing
 
Imported raw data from Excel
Cleaned and formatted datasets
Created relationships between tables:
Account Executive → Opportunities
Branch → Revenue
Meeting Date → Sales Activity

 Tools & Technologies
 
Microsoft Excel
Power BI
Tableau
SQL

Key KPIs

Total Brokerage (₹34.57M)
Total Open Opportunities
Stage Funnel Revenue
Target vs Achieved Revenue
Cross Sell / Renewal / New Business Revenue

Key Insights

High renewals ensure stable revenue flow
Cross-selling increases customer value
Low negotiation-stage conversions indicate pricing/follow-up issues
Open opportunities reflect future revenue potential
Some branches underperform against targets

 Challenges Faced
 
Handling missing values
KPI formatting issues
Managing dynamic filters
Data relationship mismatches

 Recommendations
 
Improve renewal strategies for consistent revenue
Focus on converting high-value opportunities
Increase digital adoption for renewals
Provide incentives to sales executives
Strengthen the performance of low-performing branches

 Business Impact

Improved customer retention
Increased revenue growth
Better sales productivity
Stronger pipeline conversion
Enhanced forecasting accuracy

 Conclusion

This project demonstrates how data analytics and visualization can transform insurance data into actionable insights. It enables real-time monitoring and supports data-driven decision-making for business growth.
